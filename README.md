## Recent cybersecurity news I read

### Rockstar Games data breach by ShinyHunters (April 2026)

**What happened:**
The hacker group ShinyHunters stole data from Rockstar Games and demanded a
ransom by April 14, 2026, threatening to leak it otherwise. Rockstar
confirmed the breach but said only limited, non-sensitive corporate
information was accessed and players were not affected.

**How it happened:**
It was a supply chain attack. The attackers compromised Anodot, a third-party
cloud-cost monitoring tool Rockstar uses, and stole authentication tokens
that gave them access to Rockstar's Snowflake data warehouse.

**Outcome:**
Rockstar refused to negotiate, so the data (about 8.1GB) was leaked.

**Lesson:**
Even well-defended companies can be breached through their vendors, so
third-party access and authentication tokens need strict control.

**Source:** https://securityaffairs.com/190796/data-breach/shinyhunters-claim-the-hack-of-rockstar-games-breach-and-started-leaking-data.html
